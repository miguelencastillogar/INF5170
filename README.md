# Lab de Languaje de Programacion III (INF5170)

Este portafolio reúne las prácticas y tareas de la asignatura Laboratorio de Lenguaje de Programación III. Presenta ejercicios de arquitectura web, HTML, CSS, diseño responsivo, pruebas, intercambio de datos, bases de datos, MVC, servicios web y herramientas modernas de desarrollo.

Cronograma de Actividades:

Práctica 0. Arquitectura Web y fundamentos del desarrollo moderno

Práctica 1. HTML: Página Web Personal

Práctica 2. HTML Continuación: Biografía, horario y etiquetas HTML

Práctica 3. HTML5 / CSS y diseño responsivo

Práctica 4. Menú dinámico con estructuras de datos: JSON, XML o GraphQL

Práctica 5. Pruebas Modernas para Aplicaciones Web y APIs

Práctica 5.1. Pruebas Automatizadas de UI y API con Playwright o Cypress

Práctica 5.2. Pruebas BDD con Gherkin

Práctica 5.3. Pruebas de Performance con JMeter, k6 o Postman

Práctica 6. XML, JSON y formatos de intercambio de datos

Tarea 6.1. Resumen de XML y su uso con ejemplo

Tarea 6.2. Resumen de JSON y su uso con ejemplo

Tarea 6.3. Comparación entre XML, JSON, REST, SOAP y GraphQL

Práctica 7. Acceso a Base de Datos y operaciones CRUD

Práctica 8. Modelo MVC en el desarrollo web moderno

Práctica 9. Servicios Web, REST, SOAP y APIs

Práctica 10. Framework de desarrollo, control de versiones e Inteligencia Artificial aplicada

Proyecto Final. Chatbot Web Inteligente para Consulta del Estatuto Orgánico de la UASD
