Práctica 02.2 · HTML

102 Etiquetas HTML

Catálogo de etiquetas HTML con número secuencial, descripción, ejemplo de uso y elementos adicionales para facilitar su estudio.

Introducción

HTML (HyperText Markup Language) es el lenguaje de marcado utilizado para estructurar el contenido de las páginas web. Sus etiquetas permiten identificar títulos, párrafos, enlaces, imágenes, tablas, formularios, contenido multimedia y otros elementos.

Esta práctica presenta 102 etiquetas HTML, organizadas por categorías para facilitar su lectura y estudio. Cada etiqueta incluye su número, nombre, descripción, ejemplo de uso y un elemento adicional relacionado.

La presentación se mantiene intencionalmente sencilla, dando prioridad al aprendizaje de HTML y a la organización del contenido.

Catálogo de 102 etiquetas HTML
No. Nombre de la etiqueta Descripción Ejemplo de uso Elemento adicional
1. Estructura básica y organización del documento
1 <html> Raíz del documento HTML. 
<html lang="es">...</html>
 Debe envolver todo el documento.
2 <head> Contiene metadatos e información del documento. 
<head><title>Mi página</title></head>
 No contiene el contenido visible principal.
3 <title> Define el título de la página. 
<title>102 Etiquetas HTML</title>
 Aparece normalmente en la pestaña del navegador.
4 <meta> Define metadatos del documento. 
<meta charset="UTF-8">
 Muy utilizado para codificación y viewport.
5 <link> Relaciona el documento con un recurso externo. 
<link rel="stylesheet" href="estilos.css">
 También puede utilizarse para iconos y otros recursos.
6 <style> Contiene reglas CSS internas. 
<style>body { font-family: sans-serif; }</style>
 Permite aplicar CSS directamente en el documento.
7 <body> Contiene el contenido visible de la página. 
<body><h1>Hola</h1></body>
 Solo debe existir un <body> principal.
8 <header> Representa contenido introductorio o de cabecera. 
<header><h1>Mi sitio</h1></header>
 Puede existir en la página o dentro de una sección.
9 <footer> Representa el pie de una página o sección. 
<footer>© 2026</footer>
 Suele contener autoría, derechos o enlaces.
10 <main> Contiene el contenido principal del documento. 
<main><h1>Contenido</h1></main>
 Normalmente debe existir un único <main> visible.
11 <nav> Representa un conjunto de enlaces de navegación. 
<nav><a href="inicio.html">Inicio</a></nav>
 Ayuda a la semántica y accesibilidad.
12 <section> Define una sección temática. 
<section><h2>Noticias</h2></section>
 Conviene identificarla con un encabezado.
13 <article> Representa contenido independiente. 
<article><h2>Noticia</h2><p>...</p></article>
 Útil para noticias, publicaciones o entradas.
14 <aside> Representa contenido relacionado pero secundario. 
<aside>Información relacionada</aside>
 Frecuente en barras laterales.
15 <h1> Define el encabezado de nivel 1. 
<h1>Mi página web</h1>
 Es el nivel de encabezado más importante.
16 <h2> Define un encabezado de nivel 2. 
<h2>Introducción</h2>
 Se utiliza para subdividir el contenido.
2. Texto, encabezados y listas
17 <h3> Define un encabezado de nivel 3. 
<h3>Conceptos básicos</h3>
 Permite crear una jerarquía de contenido.
18 <h4> Define un encabezado de nivel 4. 
<h4>Detalle</h4>
 Nivel inferior dentro de una estructura de encabezados.
19 <h5> Define un encabezado de nivel 5. 
<h5>Nota</h5>
 Se utiliza para niveles más específicos.
20 <h6> Define un encabezado de nivel 6. 
<h6>Referencia</h6>
 Es el nivel de encabezado menos importante.
21 <p> Define un párrafo. 
<p>Este es un párrafo.</p>
 Es uno de los elementos de texto más utilizados.
22 <hr> Representa un cambio temático. 
<hr>
 Visualmente suele mostrarse como una línea horizontal.
23 <br> Inserta un salto de línea. 
<p>Hola<br>mundo</p>
 Debe usarse para saltos de línea reales, no para espaciar contenido.
24 <pre> Muestra texto preformateado. 
<pre>Texto    con espacios</pre>
 Conserva espacios y saltos de línea.
25 <blockquote> Representa una cita extensa. 
<blockquote>Una cita importante.</blockquote>
 Puede usar cite para indicar la fuente.
26 <ol> Crea una lista ordenada. 
<ol><li>Primero</li></ol>
 Los elementos se muestran normalmente numerados.
27 <ul> Crea una lista sin orden específico. 
<ul><li>Elemento</li></ul>
 Los elementos suelen mostrarse con viñetas.
28 <li> Define un elemento de lista. 
<li>Elemento</li>
 Se utiliza dentro de listas como <ol> o <ul>.
29 <dl> Crea una lista de descripción. 
<dl><dt>HTML</dt><dd>Lenguaje de marcado</dd></dl>
 Agrupa términos y sus descripciones.
30 <dt> Define un término dentro de una lista de descripción. 
<dt>HTML</dt>
 Normalmente se acompaña de <dd>.
31 <dd> Define la descripción de un término. 
<dd>Lenguaje de marcado.</dd>
 Se utiliza dentro de <dl>.
32 <figure> Representa contenido ilustrativo independiente. 
<figure><img src="foto.jpg" alt="Foto"></figure>
 Puede contener imágenes, diagramas, código u otros recursos.
33 <figcaption> Proporciona un título o descripción para <figure>. 
<figcaption>Figura 1. Ejemplo.</figcaption>
 Se coloca dentro de <figure>.
34 <div> Contenedor genérico de bloque. 
<div class="tarjeta">Contenido</div>
 Se usa para agrupar contenido cuando no existe una etiqueta semántica apropiada.
35 <span> Contenedor genérico en línea. 
<span class="destacado">Importante</span>
 Útil para aplicar estilos o identificar pequeñas partes de texto.
36 <a> Crea un hipervínculo. 
<a href="https://example.com">Visitar</a>
 href define el destino del enlace.
37 <em> Marca énfasis semántico. 
<em>Muy importante</em>
 Los navegadores suelen mostrarlo en cursiva.
38 <strong> Indica gran importancia. 
<strong>Advertencia</strong>
 Los navegadores suelen mostrarlo en negrita.
39 <small> Representa texto secundario o de menor importancia. 
<small>© 2026</small>
 Puede utilizarse para notas legales o aclaraciones.
3. Enlaces, contenido y multimedia
40 <s> Representa contenido que ya no es correcto o relevante. 
<s>Precio anterior</s>
 No debe utilizarse simplemente para tachar texto decorativo.
41 <cite> Indica el título de una obra creativa. 
<cite>Don Quijote</cite>
 Se utiliza para referencias a obras.
42 <q> Representa una cita breve en línea. 
<q>Hola mundo</q>
 El navegador puede añadir comillas automáticamente.
43 <dfn> Marca el término que se está definiendo. 
<dfn>HTML</dfn> es un lenguaje de marcado.
 Ayuda a identificar términos definidos.
44 <abbr> Representa una abreviatura. 
<abbr title="HyperText Markup Language">HTML</abbr>
 El atributo title puede proporcionar el significado completo.
45 <data> Asocia contenido visible con un valor legible por máquina. 
<data value="123">Producto</data>
 El atributo value contiene el valor procesable.
46 <time> Representa una fecha u hora. 
<time datetime="2026-09-06">6 de septiembre</time>
 datetime permite expresar el valor de forma estructurada.
47 <code> Representa un fragmento de código. 
<code>console.log('Hola');</code>
 Ideal para código corto en línea.
48 <var> Representa una variable. 
<var>x</var> = 10
 Tiene significado semántico para variables.
49 <samp> Representa una salida de ejemplo de un programa. 
<samp>Archivo no encontrado</samp>
 Útil para mostrar resultados de sistemas.
50 <kbd> Representa una entrada del usuario mediante teclado. 
<kbd>Ctrl</kbd> + <kbd>C</kbd>
 También puede representar otros tipos de entrada.
51 <sub> Representa texto como subíndice. 
H<sub>2</sub>O
 Útil en fórmulas y notación.
52 <sup> Representa texto como superíndice. 
x<sup>2</sup>
 Útil para exponentes y notas.
53 <b> Atrae atención al texto sin añadir importancia semántica. 
<b>Palabra clave</b>
 No debe sustituir a <strong> cuando se quiere expresar importancia.
54 <i> Representa texto en una voz o modo alternativo. 
<i>Terminus technicus</i>
 Puede utilizarse para términos técnicos o expresiones diferenciadas.
55 <u> Representa una anotación no textual o subrayada semánticamente. 
<u>Palabra</u>
 No se recomienda usarla únicamente como decoración.
56 <mark> Resalta texto relevante. 
<mark>resultado encontrado</mark>
 El navegador suele mostrarlo resaltado.
57 <wbr> Indica un posible punto de salto de línea. 
super<wbr>califragilistico
 Ayuda al navegador a dividir palabras largas.
58 <ins> Representa contenido insertado. 
<ins>Texto nuevo</ins>
 Puede incluir datetime y cite.
59 <del> Representa contenido eliminado. 
<del>Texto eliminado</del>
 Puede utilizarse para mostrar cambios en documentos.
60 <img> Inserta una imagen. 
<img src="foto.jpg" alt="Paisaje">
 El atributo alt es fundamental para accesibilidad.
61 <picture> Permite ofrecer diferentes imágenes según condiciones. 
<picture><source media="(max-width:600px)" srcset="movil.jpg"><img src="pc.jpg" alt="Paisaje"></picture>
 Se usa para imágenes responsivas o formatos alternativos.
62 <source> Define una fuente de contenido para elementos multimedia. 
<source src="video.mp4" type="video/mp4">
 Se utiliza dentro de <picture>, <audio> o <video>.
63 <audio> Inserta contenido de audio. 
<audio controls src="audio.mp3"></audio>
 controls permite mostrar controles al usuario.
64 <video> Inserta contenido de vídeo. 
<video controls src="video.mp4"></video>
 Puede incluir <source> y <track>.
65 <track> Proporciona pistas de texto para audio o vídeo. 
<track kind="subtitles" src="subtitulos.vtt" srclang="es">
 Se usa dentro de <audio> o <video>.
66 <iframe> Inserta otra página o recurso HTML. 
<iframe src="pagina.html" title="Contenido"></iframe>
 Debe incluir un title descriptivo para accesibilidad.
67 <canvas> Proporciona un área de dibujo controlada mediante scripts. 
<canvas id="grafico"></canvas>
 JavaScript puede dibujar gráficos, formas e imágenes.
68 <map> Define un mapa de imagen. 
<map name="mapa">...</map>
 Se utiliza junto con <area> e imagenes con usemap.
69 <area> Define una zona interactiva dentro de un mapa de imagen. 
<area shape="rect" coords="0,0,100,100" href="inicio.html" alt="Inicio">
 Debe utilizarse dentro de <map>.
4. Tablas
70 <table> Crea una tabla de datos. 
<table><tr><td>Dato</td></tr></table>
 Debe utilizarse para datos tabulares, no para maquetación.
71 <caption> Define el título de una tabla. 
<caption>Ventas mensuales</caption>
 Debe colocarse como hijo de <table>.
72 <colgroup> Agrupa columnas de una tabla. 
<colgroup><col span="2"></colgroup>
 Permite aplicar características a grupos de columnas.
73 <col> Define propiedades de una o varias columnas. 
<col span="2">
 Normalmente se utiliza dentro de <colgroup>.
74 <thead> Agrupa las filas de encabezado de una tabla. 
<thead><tr><th>Nombre</th></tr></thead>
 Mejora la estructura semántica de tablas.
75 <tbody> Agrupa las filas principales de una tabla. 
<tbody><tr><td>Juan</td></tr></tbody>
 Puede contener una o varias filas.
76 <tfoot> Agrupa las filas finales o de resumen. 
<tfoot><tr><td>Total</td></tr></tfoot>
 Suele utilizarse para totales y resúmenes.
77 <tr> Define una fila de tabla. 
<tr><td>Dato</td></tr>
 Debe estar dentro de una tabla o sección de tabla.
78 <th> Define una celda de encabezado. 
<th>Nombre</th>
 Puede usar scope para mejorar la accesibilidad.
79 <td> Define una celda de datos. 
<td>Juan</td>
 Representa un dato dentro de una fila.
5. Formularios
80 <form> Define un formulario. 
<form action="/enviar" method="post">...</form>
 Agrupa controles para enviar datos.
81 <label> Define una etiqueta para un control de formulario. 
<label for="nombre">Nombre</label>
 for debe coincidir con el id del control.
82 <input> Crea un control de entrada. 
<input type="text" id="nombre">
 Su comportamiento depende de type.
83 <button> Crea un botón. 
<button type="submit">Enviar</button>
 Puede ejecutar acciones o enviar formularios.
84 <select> Crea una lista de opciones. 
<select><option>Rojo</option></select>
 Permite seleccionar una o varias opciones según configuración.
85 <datalist> Proporciona opciones sugeridas para un control. 
<input list="ciudades"><datalist id="ciudades"><option value="Santo Domingo"></datalist>
 Se vincula normalmente mediante el atributo list.
86 <optgroup> Agrupa opciones dentro de un <select>. 
<optgroup label="Frutas"><option>Manzana</option></optgroup>
 Facilita organizar listas largas.
87 <option> Define una opción en un control de selección. 
<option value="rd">República Dominicana</option>
 Se usa dentro de <select> o <datalist>.
88 <textarea> Crea un área de texto multilínea. 
<textarea rows="4" cols="30">Comentario</textarea>
 Es apropiado para mensajes y textos extensos.
89 <output> Representa el resultado de un cálculo o acción. 
<output name="resultado">0</output>
 Puede asociarse con controles mediante for.
90 <progress> Muestra el progreso de una tarea. 
<progress value="70" max="100">70%</progress>
 Es apropiado para procesos con progreso conocido.
91 <meter> Representa una medida dentro de un rango conocido. 
<meter min="0" max="100" value="75">75</meter>
 No debe utilizarse como barra de progreso.
92 <fieldset> Agrupa controles relacionados de un formulario. 
<fieldset><legend>Datos personales</legend>...</fieldset>
 Mejora la organización y accesibilidad del formulario.
93 <legend> Define el título de un <fieldset>. 
<legend>Datos personales</legend>
 Debe ser el primer hijo de <fieldset>.
6. Elementos interactivos y contenido especial
94 <details> Crea un panel de información expandible. 
<details><summary>Ver más</summary>Contenido</details>
 Puede abrirse o cerrarse sin JavaScript.
95 <summary> Define el encabezado visible de <details>. 
<summary>Ver detalles</summary>
 Normalmente es el primer hijo de <details>.
96 <dialog> Representa un cuadro de diálogo. 
<dialog open>Mensaje</dialog>
 Puede controlarse mediante JavaScript.
97 <menu> Representa una lista de comandos o elementos. 
<menu><li>Guardar</li><li>Salir</li></menu>
 En HTML moderno se comporta de forma similar a una lista no ordenada en muchos casos.
98 <search> Representa una sección destinada a búsquedas. 
<search><form><input type="search"></form></search>
 Es un elemento semántico para funcionalidades de búsqueda.
99 <template> Contiene HTML que no se renderiza inmediatamente. 
<template id="tarjeta">...</template>
 JavaScript puede clonar su contenido posteriormente.
100 <slot> Define un espacio para contenido en un Web Component. 
<slot name="titulo"></slot>
 Se utiliza con Shadow DOM y Web Components.
101 <script> Incluye o referencia código JavaScript. 
<script src="app.js"></script>
 Puede contener JavaScript directamente o mediante src.
102 <noscript> Define contenido alternativo cuando JavaScript no está disponible. 
<noscript>Activa JavaScript para usar esta página.</noscript>
 También puede aparecer cuando los scripts están deshabilitados.
