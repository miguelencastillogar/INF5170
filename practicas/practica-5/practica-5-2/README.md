# Práctica 5.2 - Pruebas BDD con Gherkin

## INF5170 - Laboratorio de Lenguaje de Programación III

## 1. Descripción

En esta práctica se aplica el enfoque de **Behavior Driven Development (BDD)**
para describir el comportamiento esperado de una aplicación mediante
escenarios escritos con **Gherkin**.

Como aplicación de prueba se utiliza:

**AMVERFU - Explorador Pokémon**

La funcionalidad principal seleccionada consiste en la **consulta de
información de un Pokémon mediante su nombre**.

La práctica incluye escenarios exitosos y escenarios de error para
representar diferentes comportamientos de la aplicación.

---

## 2. Objetivo

El objetivo de esta práctica es crear escenarios de prueba utilizando
BDD y Gherkin para describir el comportamiento esperado de una aplicación.

Los escenarios utilizan la estructura:

```text
Given → Dado
When  → Cuando
Then  → Entonces
