AMVERFU

Aplicación web con menú dinámico

Bienvenido a AMVERFU

AMVERFU es una aplicación web desarrollada como ejercicio académico para demostrar la creación de un menú dinámico utilizando JavaScript y JSON.

Las opciones del menú no están escritas directamente en el código HTML. Son obtenidas desde una estructura de datos JSON.

Conceptos relacionados

En esta práctica se utilizan conceptos relacionados con el intercambio de información entre aplicaciones y servicios web.

API

Una API permite que diferentes aplicaciones o sistemas puedan comunicarse e intercambiar información siguiendo determinadas reglas.

REST

REST es un estilo utilizado para diseñar servicios web que permiten acceder e intercambiar recursos mediante protocolos como HTTP.

SOAP

SOAP es un protocolo utilizado para el intercambio de mensajes estructurados entre aplicaciones y utiliza principalmente XML.

JSON

JSON es un formato ligero utilizado para representar e intercambiar datos. En esta práctica se utiliza para almacenar las opciones del menú dinámico.

XML

XML es un formato que permite representar información estructurada mediante etiquetas.

GraphQL

GraphQL es una tecnología para consultar APIs que permite solicitar los datos específicos que necesita una aplicación.
